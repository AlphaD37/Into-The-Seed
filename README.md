# 인 투 더 시드 · 웹사이트 V2

## 파일
- index.html: 페이지 구조, 기획 기반 소개 문구, SVG 일러스트, 조사 기록 창
- style.css: 색상·레이아웃·반응형·장식 애니메이션·접근성 스타일
- move.js: 페이지 인터랙션, Canvas 시각화, 전투 미니 게임, 효과음 및 로컬 설정

## 고도화한 경험
- 초록빛 입자, 포인터·스크롤 반응, 무한 흐름 타이포그래피
- 읽기 진행 표시, 현재 메뉴 강조, 모바일 메뉴, 맨 위로 버튼
- 포인터에 반응하는 특징 카드와 설계 의도 상세 패널
- 탭으로 선택하는 3단계 스킬 진화 실시간 시뮬레이션
- 직접 선택하는 5단계 플레이 루프
- 3개 기록을 읽을 수 있는 조사 기록 다이얼로그
- 일반 적 → 강화 적 → 수호자로 이어지는 3웨이브 전투
- 시드 조각 소비 강화, 회피 쿨다운, 체력 회복, 보스 공격 범위 예고
- 타격 파동·피해 숫자·파티클, 일시정지·재시작·결과 화면
- 사용자 선택형 합성 효과음(기본 꺼짐)
- 클리어 최단 기록과 모션·소리 설정의 브라우저 저장

## 전투 조작
- WASD / 방향키: 이동
- 스페이스: 진행 방향 회피(일시 무적, 재사용 대기시간)
- E: 강화(시드 4개 → 8개)
- Escape / Ⅱ: 일시정지 / 계속하기
- 모바일: 전투 영역을 드래그해 이동, 하단 버튼으로 회피와 강화
- 녹색 회복 아이템에 다가가면 체력을 회복합니다.
- 수호자의 주황색 공격 예고 범위 밖으로 이동하세요.

브라우저 탭을 떠나거나 전투 화면을 벗어나면 전투가 일시정지됩니다.
소리 설정을 켜면 브라우저 오디오 API로 만든 효과음을 재생합니다.
별도의 녹음 파일이나 외부 음원은 사용하지 않습니다.

## 접근성과 성능
- 키보드 탐색, 포커스 표시, 본문 건너뛰기, 탭 방향키 이동
- native dialog의 포커스 관리와 Escape 닫기
- 시스템의 '모션 줄이기' 및 헤더의 장식 모션 토글
- 화면 밖·백그라운드의 장식 Canvas 루프 중지
- Canvas 해상도는 기기 픽셀 비율 최대 2배로 제한
- 사운드는 사용자 조작으로 활성화
- 외부 폰트 다운로드 없이 시스템 글꼴 사용

브라우저가 로컬 저장소 접근을 차단하면 설정·기록의 영구 저장만 생략하며
페이지와 전투는 계속 동작합니다. 기기 간 동기화나 서버 저장은 없습니다.

## 기획과 체험의 구분
원본: 고민성 「AI응용게임기획 중간 과제」의 '인 투 더 시드' 기획서.
소개 페이지의 중심은 단일 스킬 성장, 자동 공격 + 이동·회피, 탑 진행,
방치 보상을 통한 도전 준비입니다.

입자·결정·탑은 소개를 위해 제작한 웹 콘셉트 시각화입니다.
기록 문장은 세계관 기반 각색이며 게임 내 확정 원문이 아닙니다.
3개 웨이브, 수호자의 공격 패턴, 통합 강화, 비용, 회복 아이템,
클리어 기록 및 전투 수치는 웹 체험을 위한 예시입니다.
실제 게임 빌드, 사전예약, 계정, 스토어, 결제·광고 연동은 포함하지 않습니다.
출시 일정이나 확정 게임 수치로 제시하지 않습니다.
